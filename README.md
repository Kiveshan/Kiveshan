## About

I work at the intersection of backend services and cloud infrastructure — writing Node.js APIs, modelling PostgreSQL schemas, and provisioning AWS infrastructure. I own the full stack from architecture decision to post-launch incident response, without a separate DevOps function.

- 🔬 Adding a Neo4j knowledge graph layer to a data lakehouse for multi-hop skills-sector traversal queries

## Featured Projects

### 🏗 AWS Data Lakehouse & Analytics Platform
> `AWS Glue (PySpark)` · `DMS` · `Step Functions` · `S3` · `RDS` · `Neo4j` · `Node.js`

End-to-end data lakehouse for a government sector skills planning client. Ingests ~750,000 records per nightly run from Azure SQL via DMS into S3-backed raw → curated → serving layers. Orchestrated in Step Functions with automatic failure recovery. Currently extending with a Neo4j knowledge graph for multi-hop entity traversal.

- ✅ Running unattended since August 2025
- ✅ 400+ entities in a Kimball-compliant dimensional schema with SCD Type 2
- ✅ Replaces costly multi-join relational queries for deeply connected lookups
